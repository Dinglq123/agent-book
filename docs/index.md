1. **第一部分 · NLP 基础** —— NLP 基本概念 → Transformer → 预训练模型 → 大语言模型
2. **第二部分 · 提示工程** —— Prompt Engineering 核心技巧：总结、推断、转换、扩展
3. **第三部分 · 模型调用** —— 核心参数、HTTP API / SDK、深度思考、流式消息、工具调用、结构化输出
4. **第四部分 · RAG** —— 检索增强生成：数据加载、向量嵌入、混合检索、查询优化
5. **第五部分 · Agent** —— 构建智能体：经典范式、低代码平台、框架开发、上下文工程
6. **第六部分 · 本地部署** —— Ollama 入门到 vLLM 服务化部署实践
7. **第七部分 · 推理工程** —— 瓶颈分析、单机优化、分布式并行策略
